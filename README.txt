DUNN FILMS — Sitio web de demostración
======================================

ARCHIVOS
- index.html: contenido y estructura.
- styles.css: diseño, colores, animaciones y adaptación a móvil.
- script.js: menú móvil, año automático y animaciones al desplazarse.

CÓMO VERLA EN TU IPAD
Opción sencilla:
1. Descomprime dunn_films_web.zip en la app Archivos.
2. Para una vista local, abre index.html. Dependiendo de iPadOS, algunas funciones o fuentes externas pueden no mostrarse igual que en internet.
3. Para verla como un sitio real, publícala gratis siguiendo las instrucciones de abajo.

PUBLICAR GRATIS CON GITHUB PAGES
1. Con ayuda de un adulto, crea o usa una cuenta en GitHub.
2. Crea un repositorio público llamado dunn-films-web.
3. Sube index.html, styles.css y script.js a la raíz del repositorio.
4. En el repositorio, abre Settings > Pages.
5. En “Build and deployment”, elige “Deploy from a branch”; selecciona “main” y “/(root)”, y guarda.
6. Espera unos minutos. GitHub mostrará una URL similar a https://TUUSUARIO.github.io/dunn-films-web/
7. Abre esa URL en Safari en tu iPad.

COSTE
- Los archivos no cuestan nada.
- GitHub Pages puede alojar gratuitamente este sitio estático.
- Un dominio propio es opcional y normalmente cuesta dinero.
- No hay formularios de envío ni base de datos. El botón de contacto abre un correo electrónico.

ANTES DE PUBLICAR
- Confirma con la empresa que el correo de contacto sigue activo.
- Sustituye o añade el logotipo oficial y fotos autorizadas cuando te las faciliten.
- Revisa los textos con DUNN FILMS. La página usa la información facilitada por el usuario y evita incluir razón social, tipo societario y RUC.
- El proyecto educativo se presenta como experiencia asociada; no afirma que haya ganado un premio.
- Esta es una web estática informativa; no incluye panel de administración, sistema de pedidos ni backend.
